# Beefcake

A text-based adventure game about a dog going on a quest to look for his ball. Personal side-project to practise Vue and Figma. 

**Please note that the project is currently still in development and is not finished.**

[Link to live version](https://maria-jon.github.io/beefcake/)

[Link to Figma Prototype](https://www.figma.com/proto/aOXmfRADc1KSljTs23zX7W/Beefcake?t=1cEmnhxgDVdS8kKs-1)
